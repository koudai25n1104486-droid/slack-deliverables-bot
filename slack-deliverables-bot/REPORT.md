# 好きな時に最新の制作物を見る（v0.7.0）

## Slackでの使い方

指定した収集元チャンネルで、ボットをメンションして送ります。

```text
@制作物まとめ 今週の制作物
```

その投稿のスレッドに、今週月曜0時から集計開始時点まで（日本時間）の件数と分類別のファイル名リンクを返します。
チャンネル参加者は誰でも利用でき、個人IDの登録は不要です。既存のスレッド内で指示した場合は、そのスレッドへ返答します。

次の表現でも同じ動作です。

```text
@ボット 最新の制作物
@ボット 今すぐ集計
@ボット 報告
@ボット 報告を見せて
@ボット レポート
```

## 表示例

```text
［あなた］@ボット 今週の制作物
└─ スレッド
    今週の制作物（随時集計）
    対象期間：2026/11/16 00:00〜2026/11/18 15:00
    2投稿・2項目

    イラスト
      ・架空作品.png → 元投稿
    動画
      ・サンプル.mp4 → 元投稿
```

## 週次報告との違い

| 機能 | 対象期間 | 表示先 |
|---|---|---|
| 随時集計 | 今週月曜0時〜その時点 | 指示した投稿のスレッド |
| 週次の定期報告 | 前週月曜0時〜今週月曜0時 | 設定したチャンネルとCanvas |

随時集計ではCanvasの追記・ピン留め・週次の処理済み記録の更新は行いません。何度見ても週次報告は実行済みになりません。予定曜日・時刻も変更しません。

## 初回の追加設定

コードを更新して、既存の.env・.stateを引き継ぎます。

```bash
npm ci --ignore-scripts
```

メンションによる曜日変更が既に動いている場合、Slackの追加権限・追加イベント設定は不要です。
まだ設定していない場合は、[SCHEDULE.md](SCHEDULE.md) に従い、`app_mentions:read` と `app_mention` を追加して再インストールします。
履歴取得に `channels:history`（プライベートなら `groups:history`）、返答に `chat:write` を使います。

## 自動投稿を止めたまま練習

```dotenv
ENABLE_MENTION_COMMANDS=true
ALLOW_SLACK_POST=true
ENABLE_WEEKLY=false
```

```bash
npm start
```

指定の収集元チャンネルに、架空の画像等を `#制作物-イラスト` 等の本文タグ付きで投稿します。
続けて、Slackの候補から実際のボットをメンションし、`今週の制作物` と送ってください。
制作物が0件の場合も、その旨を返答します。

## 制限とエラー

- 指定した収集元チャンネルだけで使えます。他チャンネル・ボット・利用者不明・古いイベントは扱いません。
- ボットが起動中で、ネットワーク接続がある場合に利用できます。稼働環境の停止・スリープ中は返答できません。
- 同じボットでの随時集計は開始から30秒間隔です。連続要求には待機を案内し、履歴を繰り返し取得しません。
- 同じプロセス内では週次処理と随時集計を順番に実行します。週次処理中は返答まで待つ場合があります。複数の稼働プロセスで同時運用しないでください。
- 件数・ページ数は既存の `MAX_ITEMS` と `MAX_PAGES` を使います。上限超過や取得失敗の場合は、集計失敗を案内します。
- 表示中に通信エラーがあれば残りの内容を自動で再送せず、部分表示の可能性を案内します。時間を空けて新しく指示してください。
- スレッドへの制作物投稿は対象外です。チャンネル本体の `#制作物` または `#制作物-分類名` 付きの人の投稿を対象にします。
- 画像・添付本体をダウンロードせず、元投稿リンクを表示します。ファイル名に個人情報等が含まれる可能性は週次報告と同じです。

## 保存・申請向け説明

随時集計のため対象期間の投稿履歴を追加で一時取得し、稼働環境のメモリでタグを判定します。結果本文・ファイル名・画像本体をサーバーへ永続保存しません。
メンションイベントの重複防止用識別子は、従来どおり `.state/schedule.json` に記録します。指示本文・利用者ID・結果本文は保存しません。週次の `.state/ledger.json` は変更しません。

学校への説明には以下を追加できます。

> 対象チャンネルの参加者がボットをメンションすると、今週月曜からその時点までの制作物を随時集計し、その指示のスレッドへ分類別のリンク一覧を返す機能です。週次報告とCanvasの蓄積とは別の閲覧機能として動作し、予定設定や週次の処理済み記録は変更しません。既存のSlack権限を使用し、外部AI・外部ストレージへの送信は行いません。
