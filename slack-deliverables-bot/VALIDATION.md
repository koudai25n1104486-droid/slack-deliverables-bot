確認日：2026年11月14日（日本時間）

- Node.js 24.14.0 / npm 11.9.0
- Bolt for JavaScript 4.7.3（package-lock.json同梱）

- 分類版で依存パッケージの追加・バージョン変更はありません。上記の依存監査は同じBolt依存構成に対する結果です。
- 実際のBoltを読み込んだ構築テスト：未起動状態でHTTPリクエストを発生させず、HTTP受信サーバーも作成しないことを確認

## 主な検証内容

- 日本時間の週境界・年またぎ・テスト期間
- 期間外・雑談・他ボット・スレッド返信・似た文字列の除外
- 添付付き投稿・複数ファイル・次ページ・重複したAPI応答
- 取得件数上限と不完全な応答での投稿停止
- ファイル名のメンション／書式埋め込みへの対処と元リンクのドメイン検証
- 読み取りプレビューで投稿・状態保存を行わないこと
- 投稿無効時の通信抑止、親投稿・返信・ピン留め、同期間の再投稿抑止
- 通信結果不明・返信途中の障害時の自動再送抑止
- ピン留めだけの再試行、プロセス間ロック、破損した状態ファイルでの停止
- ローカル実行記録にファイル名・投稿者ID・トークンを保存しないこと
- 分類リストの設定検証、本文タグの解析、未指定・候補外・削除された候補の「制作物」への振り分け
- URL内の文字列や似たタグの除外、複数タグの先頭優先、旧分類ファイルを参照しないこと
- 分類ごとの見出し・長い一覧の分割・タグからの分類読み取り
